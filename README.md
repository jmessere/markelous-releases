# Markelous

**Markdown made marvelous**

Markelous is a free Markdown editor for Windows.

This repository contains official Windows installers and release notes for Markelous.

## Download

Visit the [latest release](../../releases/latest) to download the newest version.

## Installation

1. Download the Windows installer from the latest release.
2. Run the installer.
3. Follow the installation instructions.

## Source Code

The Markelous application source code is maintained privately. This repository is used exclusively for distributing official application releases.
